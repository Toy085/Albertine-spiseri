# Albertine spiseri

Demo: https://albertine-spiseri-live.vercel.app/

## Developing

To start a development server run this:

```sh
npm run dev

# or start the server and open the app in a new browser tab
npm run dev -- --open
```

## Building

To create a production version of your app:

```sh
npm run build
```
